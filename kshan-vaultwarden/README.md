# Vaultwarden

Self-hosted, lightweight Bitwarden-compatible password manager for umbrelOS.

- Upstream: [dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden) (unofficial, not affiliated with Bitwarden)
- Image: `vaultwarden/server` (pinned by digest)
- Bitwarden clients need HTTPS: use Tailscale Serve, Umbrel's local HTTPS, or your own reverse proxy.
- Admin page: `/admin`, unlocked with the admin token shown in Umbrel.
